<ins>**Overview**</ins>

Scrapfire is a wave-based zombie survival shooter built in Unity 6. Players must survive against incoming zombie threats, manage ammunition, earn money from eliminating enemies, and navigate indoor/outdoor survival environments.

<ins>**Core Mechanics Implemented (Alpha):**</ins>

* Player Movement & Combat
* Enemy AI & Navigation
* Combat & Economy System
