# 游戏按键参考

这是目标按键表，不代表本轮全部实现。新增交互、近战、蹲下、翻越、体力和投掷功能按后续计划开发。

| 按键 | 功能 | 约定 |
|---|---|---|
| 1、2 | 武器槽 | 切换两个独立武器槽；空槽会收起武器 |
| 5 | 医疗物品 | 短按使用推荐物品；长按打开医疗轮盘 |
| F | 交互 | 与当前可交互目标交互 |
| V | 近战攻击 | 独立于当前枪械开火操作 |
| C | 蹲下 | 默认按住；降低角色高度，以通过较矮区域 |
| Space | 跳起／翻越 | 根据角色周围环境执行对应动作 |
| Tab | 背包 | 打开／关闭完整分区背包界面 |
| R | 武器换弹 | 给当前武器换弹 |
| Shift | 冲刺 | 按住；目标设计包含体力消耗 |
| G | 手榴弹 | 丢出手榴弹 |

鼠标滚轮只在已携带且已解锁的武器间切换。
N 为可选的后期武器装配面板快捷键。
现有原型仍使用 WASD 移动、鼠标瞄准、鼠标左键开火。

目前医疗轮盘和完整背包只有面板事件，没有可见 UI；冲刺已有速度倍率，没有体力消耗。
本轮不新增 F、V、C、Space、G 的功能，也不增加体力系统。

生存原型更新：F 已接入附近区域购买（PlayerInteractor），扣除当前玩家余额并解锁整个区域。
V、C、Space、G 和体力仍未实现。详见 [Survival.md](Survival.md)。

枪械原型现已接入鼠标左键射击、按住右键瞄准，使用开镜散布、禁止疾跑，并将移速乘以 0.4。步枪可按住连续射击，霰弹枪、手枪、狙击枪需要每次重新按下。详见 [Weapons.md](Weapons.md)。

背包更新：武器固定两个槽，3/4 不再切换额外武器。弹药、医疗、补给、消耗品与配件共用通用格，护甲有独立槽。当前不新增背包 UI，具体 API 见 [Inventory.md](Inventory.md)。
